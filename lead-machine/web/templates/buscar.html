A coleta automática entra na Fase 2. O formulário abaixo já define os parâmetros da busca, mas o app ainda não consulta nenhuma fonte externa — e não vai consultar nenhuma que não seja permitida. Enquanto isso, use Leads → Importar CSV para carregar uma base que você já tenha.
O que falta decidir antes de ligar a coleta
  • Google Places API (Text Search + Place Details) — a fonte mais completa para negócio local. É paga, cobrada por requisição, exige conta de faturamento no Google Cloud e chave própria. O termo de uso limita armazenamento e exibição dos dados; parte dos campos não pode ser retida. Antes de integrar, é preciso conferir a documentação oficial vigente e o preço em vigor.
  • OpenStreetMap / Overpass API — gratuita e aberta (ODbL, exige atribuição). Cobertura de negócios é irregular e quase nunca traz avaliação, nota ou site.
  • Importar CSV — disponível agora, sem custo e sem dependência externa.

Raspagem do Google Maps não está no plano: viola os termos de uso.
